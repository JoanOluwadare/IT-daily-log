# Notes
- The AeroOps platform is the core backend platform. It's designed to handle growth and increase. It distributes data effectively across ready-to-go database systems like Amazon RDS, using load balancers and vertical scaling if necessary to ensure smoothness even during heavy traffic.
- Offloading long-running and non-critical tasks to background workers frees it up for smoothly responding to user requests.
- A special layer is used to store frequently accessed data, reducing the load on the database.
- As defined in the security-architecture.md, authentication is handled via JSON Web Tokens.
- Access to privileges in the AeroOps platform is determined by the role of the user, and the user's role is checked before request is authorised.
- The ecosystem has an assigned secrets' management solution for storing all credentials to ensure security.
- system-overview.md gives a concise overview of the architecture of the AeroOps ecosystem.
