# Notes
- The central server serves as the single source of truth and manages all data and communication. There's no direct communication between clients, only with the server.
- The mobile application is designed to function completely offline for the possibility of operations in places with poor internet connection.
- AeroOps uses AI to manage and simplify aerial operations for professional drone management, commercial operations and regulatory oversight. It's designed with the unique operating environment in mind.
- The ml/overview.md file gives a high-level summary of AI features in the AeroOps. For AeroOps, AI isn't just a feature, it's an intrinsic component.
- AI features are designed to assist, not replace the pilot, so all suggestions require human approval.
- Through AI-powered speech-to-text feature, the pilot can log events hands-free. AI also generates a mission summary post-flight.
- The product/assumptions-and-constraints.md document outlines the main goals and limits that guide how AeroOps is designed.
- A limited amount of data is stored on the mobile device, and only tasks necessary for upcoming tasks are to be downloaded.
- The platform is not designed for personal interest, but for professional organisations.
- The pilot edition for AeroOPs only focuses on basic mission planning, offline executive and data synchronisation.
- This document lists all the features and rules required for the AeroOps platform. It also states the 'why' for the platform and how it aims to solve those problems. The ecosystem contains the Hub, the desktop app and the mobile app, each with its features, and the non-functional requirements.
- The desktop app is the primary hub for managing drone operations. It's the main interface for managers and administrators to plan missions and oversee operations.
