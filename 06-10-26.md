# Notes
- The desktop app uses AI to calculate flight risks. It also generates automated mission and project reports, with optional cloud fallback if the report cannot fails to be generated locally on the computer. This feature can be used in different configurations - local first, cloud first, or a balanced mix of both. 
- App controllers are a bridge between the UI and backend logic that routes user actions to services, but don't handle any heavy data processing. 
- The app incorporates a new system that plans flight paths for any type of drone. 
- Assets (icons, buttons and images) are packed into the app itself for fast running without offline. They are also kept separate from the underlying code so they can be easily redefined without breaking how it works. 
- config/README.md contains template files that tell developers how to build and prepare the software, unlike app/config/ which controls what happens while the app is open and running. The app also uses a local database to store the app user's data on the device.
